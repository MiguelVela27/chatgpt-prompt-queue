# Code of Conduct

## Our standard

This project welcomes technical discussion, bug reports, and contributions from people with different levels of experience.

Participants are expected to:

- Be respectful and constructive.
- Critique ideas and code rather than people.
- Provide enough technical context for others to reproduce problems.
- Avoid harassment, discrimination, personal attacks, or intentionally disruptive behavior.
- Protect privacy: never publish another person's private ChatGPT content, credentials, tokens, account information, or other sensitive data.

## Project scope

Discussion should remain relevant to ChatGPT Prompt Queue, userscript behavior, browser compatibility, maintenance, documentation, and related engineering decisions.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates these expectations and may restrict participation when necessary to protect contributors or the project.

Security-sensitive reports should follow `SECURITY.md` rather than being posted with exploit details in public issues.
